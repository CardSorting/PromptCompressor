# Changelog

All notable PromptCompressor changes are recorded here. The project follows a lightweight release history until a formal versioning policy is adopted.

## [0.1.0] — 2026-09-20

- Created the standalone PromptCompressor package from the reusable GALXAI compaction and query-spend surfaces.
- Added package-level prompt, context, output, cache, pricing, routing, governance, and BroccoliDB exports.
- Added the canonical documentation suite, agent knowledge base, ADRs, provenance guide, and documentation audit.
- Declared Apache-2.0 licensing for the standalone distribution with explicit third-party and extracted-source boundaries.
